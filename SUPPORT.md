# Support

## Found a bug?

Please [open a GitHub issue](https://github.com/jamesbmarshall/pokemon-tcg-tracker/issues/new/choose).
Include:

- how you deployed it (VPS/Docker, Azure, Unraid/NAS, or local dev),
- the version shown in **Settings → System**,
- your browser and OS,
- steps to reproduce, and
- any relevant log output (`docker logs poketracker` or your platform's equivalent).

## Found a security vulnerability?

**Please don't open a public issue.** Instead, open a
[private security advisory](https://github.com/jamesbmarshall/pokemon-tcg-tracker/security/advisories/new)
on the repository. See the [Security section of the README](README.md#security) for
what's already covered (auth, sessions, sharing, signed updates, audit log).

## Have a question or a feature idea?

Use [GitHub Discussions](https://github.com/jamesbmarshall/pokemon-tcg-tracker/discussions)
for anything that isn't a bug report — deployment questions, feature requests, or
general feedback from beta testing.

## Beta testing

If you're trying PokéTracker during its beta period, see [BETA.md](BETA.md) for what to
expect and how feedback during this phase is handled.
